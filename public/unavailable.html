Cette page n'est pas accessible par USB

Le firmware WLED n'expose que l'API d'état sur le port série (deserializeState). Les pages de réglages, l'éditeur de fichiers et la mise à jour OTA passent uniquement par son serveur HTTP, inaccessible ici puisque le module n'est pas sur le réseau.

Ce qui reste possible depuis le pont :

  • tout le contrôle temps réel (couleurs, effets, palettes, segments, presets) ;
  • la mise à jour du firmware par le bootloader série, via la page du pont ;
  • la configuration durable, en reflashant une image qui l'embarque.
